Generar un procedimiento

¿Qué hago aquí? Le dice qué comandos usar para recuperar; solo se ejecutan si usted los aprueba y los confirma
  1. Diagnostique primero: suba al panel «Diagnóstico» (arriba de este) y pulse «Diagnosticar ahora». El sistema detecta qué archivo está dañado y le muestra ahí mismo el procedimiento sugerido, listo para revisar y aprobar. Este formulario sirve cuando necesita otro escenario o no hay daños que diagnosticar.
  2. Elija qué pasó en el primer campo.
  3. En «Objeto dañado» escriba qué se dañó (una PDB, un tablespace o un archivo). Si lo deja vacío, el sistema lo deduce del diagnóstico.
  4. Pulse Generar procedimiento y revise los pasos y el script.
  5. Apruébelo con su nombre: queda fijada la huella SHA-256 del script. Después aparece el botón Ejecutar procedimiento: marque la confirmación y púlselo para que RMAN lo ejecute.

Si la base está sana, el sistema responderá «No es posible» porque no hay nada que recuperar: es normal.

«Objeto dañado» cambia según la falla que elija: nombre de la PDB, tablespace, número de archivo, miembro de redo log, secuencia o bloque. En «control file», «SPFILE» y «recuperación total» no se necesita. «Hasta» solo sirve para volver a una hora exacta.
